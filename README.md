# Eagle JXL 変換プラグイン

Eagleで選択した画像をJPEG XL（`.jxl`）形式に変換するプラグインです。libjxlの`cjxl`コマンドを使って変換し、変換後のファイルでEagle内の元ファイルを置き換えます。

## 主な機能

- Eagleで選択した画像をまとめて変換
- 画質（Quality）と圧縮速度・圧縮率のバランス（Effort）を指定
- 変換対象の件数、拡張子内訳、処理状況を表示
- 変換結果で元ファイルを置き換え、Eagleのアイテム情報を維持

## 動作要件

- Eagle デスクトップアプリ
- お使いのOSに対応したlibjxlの`cjxl`実行ファイル

このリポジトリには、サイズとOS依存のため`cjxl`バイナリは含まれていません。libjxlの配布元からOSに合ったバイナリを入手し、次の場所に配置してください。

| OS | 配置するファイル |
| --- | --- |
| Windows | `bin/cjxl.exe` |
| macOS / Linux | `bin/cjxl` |

## インストール

1. このリポジトリのプラグインフォルダを用意します。
2. 上記の場所に`cjxl`実行ファイルを配置します。
3. Eagleのプラグイン管理からプラグインをインストールして起動します。開発時はEagleの「プラグイン」メニューにある開発者オプションを利用してください。

起動時にエンコーダーが見つからない場合は、画面のログに必要な配置先が表示されます。

## 使い方

1. Eagleで変換したい画像を選択します。
2. 「JXL 変換」プラグインを開きます。
3. 品質とEffortを設定します。
4. 「変換を実行」をクリックします。
5. 進捗と成功・失敗件数を画面のログで確認します。

### 設定

- **品質（Quality）**: 1〜100。100未満は指定品質の非可逆圧縮です。値を大きくすると画質を保ちやすくなります。
- **Effort**: 1〜9。値を大きくすると圧縮処理に時間がかかる一方、圧縮率が向上する場合があります。7が初期値です。
- **品質100**: JPEGは画質を保つJPEG-to-JXL変換を行います。JPEG以外の対応形式は可逆圧縮（distance 0）で変換します。

### 対応入力形式

PNG、JPG、JPEG、GIF、APNG、WebP、BMP、EXR、PAM、PPMに対応しています。選択中のJXLファイルおよび上記以外の形式は変換対象になりません。

## 注意事項

- 変換は新しいEagleアイテムを作るのではなく、選択したアイテムのファイルをJXLに置き換えます。元の形式のまま残す場合は、事前にバックアップを取ってください。
- 変換後の画像ビューアや他アプリでの互換性は、利用するアプリがJPEG XLに対応しているかによります。
- 複数画像は順番に処理されます。失敗した画像があっても、残りの画像の処理は続行します。

## 開発・パッケージ

プラグインのエントリーポイントは`src/index.html`です。Eagleのプラグイン管理からプラグインをパッケージ化する場合は、Eagleのプラグイン画面で対象プラグインを右クリックし、「プラグインをパッケージ化」を選択します。
